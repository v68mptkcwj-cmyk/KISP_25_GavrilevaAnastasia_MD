# Введение в JavaScript

**JavaScript (JS)** — это независимый язык программирования со своей собственной спецификацией (ECMAScript). Изначально он создавался для того, чтобы «сделать веб-страницы живыми», но сегодня может выполняться на сервере (Node.js) и любых других устройствах.

---

## Что такое скрипты и как они работают

Программы на языке JavaScript называются **скриптами**. Они встраиваются в HTML-код и выполняются в браузере автоматически при загрузке страницы.

### Как устроен JavaScript-движок (виртуальная машина)

Для выполнения кода на устройстве должна быть установлена специальная программа — **движок**.

|Название движка|Где используется|
|---|---|
|`V8`|Chrome, Opera, Edge|
|`SpiderMonkey`|Firefox|
|`JavaScriptCore` / `Nitro`|Safari|

#### Этапы работы движка:
1. **Парсинг:** Движок читает («парсит») текст предоставленного скрипта.
2. **Компиляция:** Преобразует (компилирует) скрипт в машинный язык.
3. **Оптимизация:** Движок анализирует данные прямо во время работы кода и оптимизирует полученный машинный код для максимальной скорости.


## Возможности и ограничения JS в браузере

JavaScript спроектирован как безопасный язык. Внутри браузера его возможности намеренно ограничены, чтобы вредоносные сайты не могли нанести ущерб данным пользователя.

### Сводная таблица возможностей в браузере

|Что JavaScript МОЖЕТ делать|Чего JavaScript НЕ МОЖЕТ делать (Ограничения)|
|---|---|
|Изменять HTML-код страницы, существующий контент и CSS-стили.|Читать, записывать или запускать произвольные файлы на жестком диске смартфона или ПК без ведома пользователя.|
|Реагировать на клики мыши, прокрутку, нажатия клавиш клавиатуры.|Незаметно включать камеру или микрофон (для доступа всегда требуется явное разрешение пользователя).|
|Отправлять запросы на сервер, скачивать и загружать файлы (AJAX).|Иметь доступ к данным соседних вкладок, если они открыты на других сайтах (**Политика одинакового источника / Same Origin Policy**).|
|Работать с куками (`cookies`) и локальным хранилищем клиента (`local storage`).|Свободно получать данные с чужих доменов и серверов без их явного согласия в HTTP-заголовках.|


## Что делает JavaScript уникальным

JavaScript занимает уникальную позицию в веб-разработке благодаря **трем главным сильным сторонам**:
1. Полная интеграция с HTML-разметкой и CSS-стилями.
2. Простые задачи делаются просто и лаконично.
3. Поддерживается абсолютно всеми основными браузерами и включен в них по умолчанию.

## 4. Языки «над» JavaScript (Транспиляция)

Код на этих вспомогательных языках автоматически **транспилируется** (конвертируется) в обычный JavaScript перед тем, как запуститься в браузере.

### Популярные транспилируемые языки

|Название языка|Главная цель и назначение|Кто разработал|
|---|---|---|
|`TypeScript`|Добавляет строгую типизацию для упрощения поддержки крупных и сложных программных систем|Microsoft|
|`CoffeeScript`|Вводит «синтаксический сахар» — максимально короткий синтаксис для лаконичного кода|Сообщество|
|`Flow`|Добавляет проверку типов данных альтернативным способом|Facebook|
|`Dart`|Имеет собственный движок вне браузера, активно используется в мобильных приложениях|Google|
|`Brython`|Преобразует код на языке Python в JavaScript, позволяя писать фронтенд без JS|Сообщество|

**Важно:** Даже если вы пишете код на TypeScript или Dart, необходимо знать основы самого JavaScript, чтобы понимать принципы работы готового приложения.

# Справочники и спецификации

**Концепция:** Учебник помогает освоить язык постепенно, но практикующему разработчику критически важно уметь работать с первоисточниками — официальными спецификациями, подробными справочниками методов и таблицами совместимости браузеров.


## Официальная спецификация (ECMAScript)

Самая глубокая, детализированная и авторитетная информация о поведении JavaScript содержится в официальных стандартах.

|Название ресурса|Назначение и особенности|Ссылка|
|---|---|---|
|`ECMA-262`|Официальная спецификация. Содержит максимально формализованный текст, определяющий стандарты языка.|[tc39.es/ecma262](https://tc39.es)|
|`TC39 Proposals`|Репозиторий со списками новых возможностей, которые находятся на стадии рассмотрения и внедрения в стандарт (Stage 3).|[://github.com](https://://github.com)|

* Спецификация обновляется **каждый год**. Из-за сложного академического стиля она не подходит для ежедневного использования новичками, но является главным документом для разрешения спорных моментов в работе движков.

## Практические справочники для ежедневной работы

Для быстрого поиска синтаксиса, аргументов функций и примеров кода используется документация от сообщества разработчиков.

* **MDN Web Docs (Mozilla JavaScript Reference)** — основной и самый популярный справочник. Содержит исчерпывающую информацию о встроенных объектах, методах, функциях и структурах данных с живыми примерами.

**Лайфхак:** Вместо ручного поиска по сайту MDN, быстрее вбивать в строку любого поисковика прямые запросы. Например: `MDN parseInt` или `MDN Array map`.

# Редакторы кода

> **Концепция:** Выбор рабочего инструмента индивидуален и зависит от масштаба проекта, привычек разработчика и мощности компьютера. Все редакторы делятся на два основных типа: мощные IDE и быстрые «лёгкие» редакторы.

## 1. Интегрированные среды разработки (IDE)

**IDE (Integrated Development Environment)** — это тяжеловесные программные комплексы, предназначенные для комплексного управления целыми проектами. 

### Возможности IDE:
* Полноценный анализ структуры всего проекта, а не только открытых файлов.
* Глубокое «умное» автодополнение кода на основе связей между модулями.
* Встроенная бесшовная интеграция с системами контроля версий (например, `Git`), отладчиками и тестовыми фреймворками.

### Популярные IDE для JavaScript

|Название IDE|Платформа|Условия распространения|Особенности|
|---|---|---|---|
|`Visual Studio Code`|Кроссплатформенная|Бесплатная|Самый популярный редактор, расширяемый плагинами|
|`WebStorm`|Кроссплатформенная|Бесплатная для некоммерческого использования|Специализированная мощная среда от JetBrains|
|`Visual Studio`|Только Windows|Платная (есть бесплатная версия Community)|Мощная среда, лучше всего подходящая для .NET|

## 2. «Лёгкие» редакторы кода

«Лёгкие» редакторы ориентированы на максимальную скорость запуска, простоту интерфейса и минимальное потребление ресурсов компьютера.

### Основные сценарии использования:
* Быстрое открытие и точечное редактирование одного конкретного файла.
* Работа на слабых устройствах, где полноценные IDE могут вызывать задержки интерфейса.

# Консоль разработчика

**Концепция:** По умолчанию ошибки JavaScript скрыты от глаз обычных посетителей сайта. Для их поиска, анализа и исправления во все современные браузеры встроены специальные инструменты разработки — **Developer Tools** (или коротко **DevTools**).

## Горячие клавиши для открытия консоли

Способ вызова встроенных инструментов разработки зависит от операционной системы и конкретного веб-браузера.

|Браузер|Клавиши на Windows / Linux|Клавиши на macOS|Особенности|
|---|---|---|---|
|`Google Chrome`|`F12`|`Cmd + Opt + J`|Открывает DevTools сразу на вкладке **Console**|
|`Firefox / Edge`|`F12`|`F12`|Интерфейс и принципы работы аналогичны Chrome|
|`Safari (Mac)`|Не поддерживается|`Cmd + Opt + C`|Требует предварительной активации в настройках|

**Инструкция для Safari:** Перед первым запуском необходимо открыть *Настройки (Preferences)* вкладка *Продвинутые (Advanced)* поставить галочку в самом низу на пункте *«Показывать меню "Разработка" в строке меню»*.


## Анатомия окна консоли

При возникновении сбоя в работе скрипта, на вкладке **Console** отображаются следующие данные:
* **Текст ошибки:** Описание проблемы (например, вызов несуществующей команды), подсвеченное красным цветом.
* **Место сбоя:** В правой части строки выводится кликабельная ссылка на исходный файл и точный номер строки, где движок зафиксировал ошибку (например, `index.html:12`).

## Запуск команд на лету

Консоль снабжена строкой ввода, которая начинается с символа синей стрелки `>`. Она работает как полноценная интерактивная среда программирования.

### Правила работы со строкой ввода:
* **Однострочный ввод:** Напишите любую валидную команду JavaScript и нажмите `Enter` для её немедленного выполнения на открытой странице.
* **Многострочный ввод:** Чтобы перенести строку и продолжить писать длинный скрипт без его мгновенного запуска, используйте комбинацию клавиш `Shift + Enter`.

## Привет, мир!

**Концепция:** Для запуска кода JavaScript нужна рабочая среда. В данном руководстве в качестве среды используется веб-браузер, однако сам язык является платформонезависимым и может запускаться на сервере (например, через команду `node file.js`).

### Тег <script>

Внутри браузера программы на JavaScript внедряются в любое место HTML-документа с помощью парного тега `<script>`. Браузер находит этот тег и выполняет его содержимое автоматически.

#### Пример встроенного скрипта:
```html
<!DOCTYPE HTML>
<html>
<body>
  <p>Перед скриптом...</p>

  <script>
    alert('Привет, мир!');
  </script>

  <p>...После скрипта.</p>
</body>
</html>
```

### 2. Современные стандарты и устаревшая разметка

В старых руководствах и древних проектах могут встречаться атрибуты тега `<script>`, которые в современном стандарте HTML5 больше не требуются.

|Устаревший синтаксис|Как это использовалось|Современный стандарт|
|---|---|---|
|`type="text/javascript"`|Был обязателен в HTML4 для указания типа данных.|**Не требуется.** В современном стандарте атрибут `type` используется только для объявления модулей (`type="module"`).|
|`language="javascript"`|Задавал язык программирования внутри тега.|**Не требуется.** JavaScript является языком по умолчанию для всех веб-браузеров.|
|`<!-- код скрипта -->`|HTML-комментарии внутри тега для сокрытия кода от старых браузеров.|**Не требуется.** Все браузеры, выпущенные за последние 15 лет, корректно понимают тег `<script>`.|


###  Подключение внешних скриптов

Если кода много, его выносят в отдельные файлы с расширением `.js`. Они подключаются к HTML-странице при помощи специального атрибута `src`.

#### Примеры подключения:
```html
<!-- Абсолютный путь от корня проекта -->
<script src="/js/main.js"></script>

<!-- Относительный путь (файл лежит в той же папке, что и HTML) -->
<script src="alert.js"></script>

<!-- Подключение сторонней библиотеки по полному URL-адресу -->
<script src="https://cloudflare.com"></script>
```

#### Критически важное правило:
В рамках одного тега `<script>` необходимо выбрать только один способ интеграции. **Нельзя одновременно указывать атрибут `src` и писать код внутри тега.**

|НЕПРАВИЛЬНО (внутренний код проигнорируется)|ПРАВИЛЬНО (разделение на два скрипта)|
|---|---|
|```html <script src="file.js"> alert('Этот код не выполнится!'); </script>```|```html <script src="file.js"></script> <script> alert('Выполнится успешно!'); </script>```|

#### Преимущества внешних файлов:
* **Кеширование:** Браузер загружает `.js` файл по сети только один раз. При переходе на другие страницы сайта он берет этот файл из локального кеша.
* **Оптимизация:** Сокращается расход сетевого трафика, и веб-страницы загружаются быстрее.

## Структура кода

**Концепция:** Изучение базовых правил построения скриптов, синтаксических команд и способов документирования логики программы.

### Инструкции (Statements)

**Инструкции** — это синтаксические конструкции и команды, выполняющие определенные действия в коде (например, вызов окна `alert()`). 
* Количество инструкций в скрипте не ограничено.
* Каждую инструкцию принято писать с новой строки для повышения читаемости кода.

```javascript
alert('Привет');
alert('Мир');
```

### Ловушки автоматической расстановки точек с запятой

В JavaScript в большинстве случаев точку с запятой `;` на конце строки можно опускать. Интерпретатор воспринимает перенос строки как неявную точку с запятой. Это называется **автоматической вставкой точки с запятой**.

* **Когда это работает:** Если выражение явно не завершено (например, строка заканчивается на знак `+`), движок понимает, что код продолжается на следующей строке.
* **Когда это ЛОМАЕТ код:** В редких ситуациях движок «забывает» поставить точку с запятой, что приводит к критическим синтаксическим ошибкам.

#### Пример опасной ошибки слияния строк:

| Код БЕЗ точки с запятой (вызовет ошибку)|Как этот код ошибочно видит движок JS|
|---|---|
|```javascript alert("Hello") [1, 2].forEach(alert); ```|```javascript alert("Hello")[1, 2].forEach(alert); ```|

**Рекомендация сообщества:** Безопаснее и надежнее всегда явно ставить точку с запятой `;` между инструкциями, даже если они отделены переносами строк.

### Комментарии в коде

Комментарии служат для описания логики работы скрипта. Они полностью игнорируются JavaScript-движком и не влияют на скорость выполнения программы.

#### Типы комментариев

|Тип комментария|Синтаксис|Пример использования|
|---|---|---|
|**Однострочный**|Начинается с двойного слэша `//`|`// Это комментарий на всю строку`|
|**Многострочный**|Оборачивается в символы `/* ... */`|`/* Закомментированный кусок кода */`|

#### Важные ограничения комментариев:
* **Вложенность запрещена:** Нельзя вкладывать один многострочный комментарий внутрь другого. Код вида `/* /* текст */ */` упадет с синтаксической ошибкой.

#### Горячие клавиши для комментирования в редакторах (VS Code)

|Тип комментария|Клавиши на Windows / Linux|Клавиши на macOS|

## Строгий режим — "use strict"

**Концепция:** Исторически JavaScript развивался с сохранением полной обратной совместимости, из-за чего все старые ошибки проектирования оставались в языке. В 2009 году стандарт ES5 ввел **строгий режим (strict mode)**, который блокирует устаревший небезопасный синтаксис и переключает движок на современную работу.

### Применение директивы

Строгий режим активируется с помощью специальной текстовой директивы `"use strict";` (или `'use strict';`).

#### Способы включения строгого режима

|Область действия|Где прописывается|Особенности|
|---|---|---|
|**Глобально (для файла)**|В самой первой строке файла скрипта.|Весь код в этом файле будет проверяться по современным стандартам.|
|**Локально (для функции)**|В самой первой строке внутри тела функции.|Современный режим включится только внутри этой конкретной функции.|

#### Критически важное правило размещения:
Директива `"use strict";` должна находиться **строго на первой исполняемой строке** скрипта (или функции). Если перед ней выполнить любой другой код, строгий режим **не активируется**.

* **Правильно:** над директивой могут находиться только комментарии.
* **Невозможно отменить:** в языке не существует директивы вида `"no use strict"`. Если строгий режим включен, вернуть движок к старому поведению в рамках этого файла нельзя.

### Особенности активации в консоли браузера

По умолчанию в консоли инструментов разработчика (`DevTools`) строгий режим **выключен**. Чтобы тестировать современный код в консоли, используйте один из двух приемов:

1. **Многострочный ввод:** Напишите директиву первой, перенесите строку через `Shift + Enter` и пишите код далее.
   ```javascript
   'use strict'; // Shift+Enter
   // ... далее ваш современный код ...
   ```
2. **Обертка в функцию (IIFE):** Поместите код в самовызывающуюся функцию.
   ```javascript
   (function() {
     'use strict';
     // ... ваш код ...
   })();
   ```

### Всегда ли нужно писать "use strict"?

В современной разработке писать эту строчку вручную приходится всё реже из-за особенностей новых стандартов языка.

* **Классы и Модули:** Продвинутые конструкции современного JavaScript (модули `import/export` и классы `class`) включают строгий режим внутри себя **автоматически** по умолчанию.
* **Итоговое правило:** На этапе изучения основ всегда добавляйте `"use strict";` в начале ваших файлов `.js`. Позже, когда вы перейдете на модульную архитектуру проекта (как в React или Expo), эту директиву можно будет полностью опускать.

## Переменные (Variables)

**Концепция:** Переменная — это именованное хранилище (или виртуальная «коробка») для данных. Переменные позволяют сохранять, изменять и копировать информацию в памяти приложения.

### Ключевые слова для объявления данных

В JavaScript существует три способа создания переменных и констант, определяющих их поведение в памяти.

|Ключевое слово|Тип данных|Возможность изменения|Современный статус|
|---|---|---|---|
|`let`|Переменная| Да (можно перезаписывать значение)|Современный стандарт|
|`const`|Константа| Нет (значение заблокировано после записи)|Современный стандарт|
|`var`|Переменная| Да (имеет специфическую область видимости)|Устаревший способ|

#### Базовые примеры использования:
```javascript
// Совмещение объявления и инициализации
let message = 'Hello!';
message = 'World!'; // Значение успешно изменено, старое удалено

// Копирование данных из одной переменной в другую
let hello = 'Hello world!';
let welcome;
welcome = hello; // Теперь обе переменные хранят одинаковую строку

// Повторное объявление одной и той же переменной вызовет ошибку!
let user = "Иван";
// let user = "Петр"; //  SyntaxError: 'user' has already been declared
```

### Жесткие ограничения именования переменных

Имя переменной в JavaScript может состоять из любых букв, цифр, а также символов `$` и `_`.

|Правило именования|Примеры правильных имён|Примеры ошибочных имён|
|---|---|---|
|Не может начинаться с цифры|`let test123;`|`let 1a;` *(Ошибка)*|
|Запрещено использование дефиса|`let userName;`|`let my-name;` *(Ошибка)*|
|Разрешены символы `$` и `_`|`let $ = 1; let _ = 2;`|`let my@name;` *(Ошибка)*|

* **Регистрозависимость:** Переменные `apple` и `APPLE` — это две абсолютно разные изолированные переменные.
* **Зарезервированные слова:** Нельзя использовать в качестве имён системные команды языка, такие как `let`, `class`, `return`, `function`.
* **Языковой стандарт:** Технически кириллица разрешена (`let имя = 'Иван'`), но по международной традиции имена всегда пишутся на английском языке в стиле CamelCase (например, `currentUserName`).

### Особенности работы с константами (`const`)

Переменные, объявленные через `const`, нельзя изменить или перезаписать после инициализации. Попытка сделать это вызовет ошибку выполнения кода.

В сообществе разработчиков константы делятся на два типа в зависимости от регистра букв:

|Тип константы|Регистр имени|Когда используется|Пример|
|---|---|---|---|
|**Жестко закодированная**|ВЕРХНИЙ (`UPPER_CASE`)|Значение известно заранее до запуска скрипта. Служит псевдонимом для сложных строк или HEX-кодов.|`const COLOR_RED = "#F00";`|
|**Вычисляемая**|Обычный (`camelCase`)|Значение вычисляется в процессе выполнения кода, но не меняется после фиксации.|`const pageLoadTime = 120;`|


### Правила хорошего тона при именовании
* **Описательность:** Имя должно четко говорить о содержимом коробки. Избегайте пустых имён вроде `data` или `value`.
* **Отказ от экономии букв:** Современные редакторы снабжены автодополнением, поэтому понятное имя из трех слов (например, `ourPlanetName`) гораздо лучше, чем короткое невнятное `p`.
* **Уважение к памяти:** Не используйте одну и ту же переменную для хранения разных по смыслу данных ради экономии строчек кода. Лишняя переменная — это благо, помогающее движку оптимизировать код.

## Типы данных (Data Types)

**Концепция:** JavaScript является **динамически типизированным** языком программирования. Это означает, что типы данных привязаны к самим значениям, а не к переменным. Одна и та же переменная в разные моменты времени может хранить сначала строку, а затем число.

В JavaScript существует **8 основных типов данных**: 7 примитивных типов и 1 ссылочный (`object`).

### Сводная таблица примитивных типов данных

Примитивы передаются по значению и содержат в себе только простые одиночные данные.

|Тип данных|Что в себе хранит|Особенности и специальные значения|Пример кода|
|---|---|---|---|
|`Number`|Целые числа и числа с плавающей точкой.|Безопасный диапазон: $\pm(2^{53}-1)$. Содержит спецзначения: `Infinity`, `-Infinity` и `NaN` (ошибка вычислений).|`let n = 12.34; let inf = 1 / 0;`|
|`BigInt`|Целые числа произвольной длины.|Используется для работы с гигантскими числами (криптография, таймстампы). Создается добавлением буквы `n` на конце.|`const bigint = 123456789n;`|
|`String`|Текстовые строки.|Нет отдельного типа для одного символа (`char`). Поддерживает 3 вида кавычек: `'`, `"` и `` ` `` (обратные).|`let text = "Привет";`|
|`Boolean`|Логический тип.|Принимает только два значения: `true` (да) и `false` (нет).|`let isChecked = true;`|
|`Null`|Отдельный тип из одного значения `null`.|Означает «пусто», «ничего» или «значение намеренно неизвестно».|`let age = null;`|
|`Undefined`|Отдельный тип из одного значения `undefined`.|Означает, что «значение еще не было присвоено переменной».|`let x; // значение undefined`|
|`Symbol`|Уникальные идентификаторы.|Используется для создания скрытых уникальных ключей внутри объектов.|`let id = Symbol("id");`|

#### Расширенные возможности обратных кавычек (Шаблонные строки):
В отличие от одинарных и двойных, обратные кавычки (бэктики) позволяют интерполировать (встраивать) в строку любые переменные и математические выражения с помощью конструкции `${...}`:
```javascript
let name = "Иван";
alert(`Привет, ${name}!`); // Выведет: Привет, Иван!
alert(`Результат: ${1 + 2}`); // Выведет: Результат: 3
alert("Результат: \({1 + 2}"); // Двойные кавычки выведут текст как есть: Результат: \){1 + 2}
```

### Ссылочный тип: Объект (`Object`)

В отличие от примитивов, тип `object` стоит особняком. Он используется для хранения коллекций данных, массивов, функций и гораздо более сложных комплексных структур. 


###  Оператор определения типа `typeof`

Оператор `typeof` анализирует аргумент и возвращает строку с названием его типа. Это незаменимый инструмент для проведения проверок перед обработкой данных.

#### Синтаксические формы:
1. Обычный оператор (рекомендуется): `typeof x`
2. Вызов со скобками (для вычисления выражений): `typeof(x)`

#### Специфика результатов работы `typeof`

|Вызов оператора|Что возвращает|Реальный тип данных / Пояснение|
|---|---|---|
|`typeof undefined`|`"undefined"`|Тип `undefined`|
|`typeof 42`|`"number"`|Тип `number`|
|`typeof 10n`|`"bigint"`|Тип `bigint`|
|`typeof true`|`"boolean"`|Тип `boolean`|
|`typeof "foo"`|`"string"`|Тип `string`|
|`typeof Symbol()`|`"symbol"`|Тип `symbol`|
|`typeof Math`|`"object"`|Глобальный встроенный объект математических функций|
|`typeof null`|`"object"`|**Официальная ошибка языка!** `null` не объект, это примитив с отдельным типом, сохраненный так для совместимости.|
|`typeof alert`|`"function"`|**Особенность typeof.** Специального типа «функция» в JS нет (они относятся к объектам), но оператор выделяет их для удобства.|

## Взаимодействие: alert, prompt, confirm

**Концепция:** Для взаимодействия с пользователем браузер предоставляет три простые встроенные функции. Все вызываемые ими окна являются **модальными** — они полностью приостанавливают выполнение кода JavaScript и блокируют любые действия пользователя на веб-странице до тех пор, пока окно не закроется.


### Сравнительная таблица встроенных окон браузера

|Функция|Назначение|Принимаемые аргументы|Возвращаемое значение при успехе|Возвращаемое значение при отмене / Esc|
|---|---|---|---|---|
|`alert`|Вывод информационного сообщения.|`title` (строка с текстом)|`undefined` (ждёт клика по кнопке «ОК»)|`undefined`|
|`prompt`|Запрос текстового ввода от пользователя.|`title` (текст) и необязательный `default` (значение в поле по умолчанию).|`String` (текст, который ввёл пользователь).|`null`|
|`confirm`|Запрос подтверждения действия (вопрос «Да/Нет»).|`question` (текст вопроса)|`true` (если нажата кнопка «ОК»)|`false`|

#### Примеры использования кода:
```javascript
// 1. Простое уведомление
alert("Привет от JavaScript!");

// 2. Ввод данных с дефолтным значением
let userAge = prompt('Сколько тебе лет?', 18);
alert(`Тебе ${userAge} лет!`); // Если нажать "Отмена", выведет: Тебе null лет!

// 3. Логическая проверка действия
let isDeleteConfirmed = confirm("Вы действительно хотите удалить этот файл?");
if (isDeleteConfirmed) {
  alert("Файл удален.");
} else {
  alert("Действие отменено.");
}
```


### Специфические особенности и ограничения

При работе со стандартными модальными окнами разработчику приходится мириться с рядом фундаментальных ограничений:

* **Отсутствие стилизации:** Внешний вид окон (шрифты, цвета, скругления кнопок) полностью диктуется операционной системой и браузером. Изменить его через CSS невозможно.
* **Фиксированное положение:** Окна всегда появляются по центру экрана. Программным образом сдвинуть их в сторону нельзя.
* **Специфика Internet Explorer:** При использовании функции `prompt` в браузере IE всегда обязательно передавать второй аргумент (хотя бы пустую строку `''`). Если этого не сделать, браузер принудительно вставит текстовое слово `"undefined"` в поле ввода пользователя.
  ```javascript
  let data = prompt("Введите текст", ''); // Идеально для кроссплатформенности, включая старый IE
  ```

# Конспект по основам JavaScript

## 1. Преобразование типов
В JavaScript существует три основных вида преобразования типов: строковое, численное и логическое.

### Строковое преобразование (`String`)
Происходит, когда требуется представление значения в виде текста (например, при вызове `alert`).
* **Синтаксис:** `String(value)`
* **Правило:** Преобразует значение в лоб (например, `true` становится `"true"`, `null` становится `"null"`).

### Численное преобразование (`Number`)
Происходит в математических функциях и выражениях.
* **Синтаксис:** `Number(value)` или использование унарного плюса `+value`.
* **Правила преобразования:**
    * `undefined` → `NaN`
    * `null` → `0`
    * `true` / `false` → `1` / `0`
    * `string` → убираются пробелы по краям. Пустая строка становится `0`, при ошибке чтения — `NaN`.

### Логическое преобразование (`Boolean`)
Происходит в логических операциях и условных конструкциях.
* **Синтаксис:** `Boolean(value)` или двойное отрицание `!!value`.
* **Правило «Пустых» значений:** Значения, которые интуитивно «пусты» (`0`, пустая строка `""`, `null`, `undefined`, `NaN`), становятся `false`. Все остальные значения (включая строку `"0"` и пустой массив) становятся `true`.

## 2. Базовые операторы, математика

### Терминология
* **Операнд** — то, к чему применяется оператор (например, в `5 * 2` два операнда: `5` и `2`).
* **Унарный оператор** — применяется к одному операнду (например, унарный минус `-x`).
* **Бинарный оператор** — применяется к двум операндам (например, `x + y`).

### Математические операторы
* Сложение `+`, вычитание `-`, умножение `*`, деление `/`.
* Взятие остатка `%` (например, `5 % 2` вернет `1`).
* Возведение в степень `**` (например, `2 ** 3` вернет `8`).

### Особенности сложения со строками
Если бинарный оператор `+` применяется к строкам, он их объединяет (конкатенирует). **Если хотя бы один операнд является строкой, то второй тоже преобразуется в строку:**

```javascript
alert('1' + 2); // "12"
alert(2 + 2 + '1'); // "41" (вычисления идут слева направо)
```

> **Важно:** Другие арифметические операторы (`-`, `/`, `*`) всегда преобразуют операнды в числа.

### Приоритет операторов
У каждого оператора есть свой приоритет (вес). Операторы с большим приоритетом выполняются раньше. Унарные операторы имеют более высокий приоритет, чем бинарные.

### Инкремент и декремент
* **Инкремент `++`** увеличивает значение на 1.
* **Декремент `--`** уменьшает значение на 1.
* **Формы:**
    * *Префиксная* (`++x`): сначала увеличивает, затем возвращает новое значение.
    * *Постфиксная* (`x++`): сначала возвращает старое значение, затем увеличивает.

## 3. Операторы сравнения
Все операторы сравнения возвращают логическое значение: `true` или `false`.

### Сравнение разных типов
При сравнении значений разных типов JavaScript приводит их к числам (исключение — строгое сравнение).

```javascript
alert('2' > 1); // true, строка '2' становится числом 2
alert(true == 1); // true
```

### Строгое сравнение (`===`)
Обычное равенство `==` имеет проблему: оно не может отличить `0` от `false` или пустую строку от `false`. 
* **Оператор строгого равенства `===`** проверяет равенство без приведения типов. Если типы разные, то сразу возвращается `false`.
* Аналогично существует оператор строгого неравенства `!==`.

### Особенности `null` и `undefined`
* При строгом равенстве `===` они не равны друг другу, так как принадлежат к разным типам.
* При нестрогом равенстве `==` они равны друг другу и не равны ничему другому: `null == undefined` возвращает `true`.
* При сравнениях на больше/меньше (`>`, `<`, `>=`, `<=`) `null` превращается в `0`, а `undefined` превращается в `NaN`. Из-за этого возникают неочевидные баги (например, `null >= 0` дает `true`, но `null == 0` дает `false`).

## 4. Условное ветвление: if, '?'

### Конструкция `if`
Инструкция `if` вычисляет выражение в скобках и, если результат `true`, выполняет блок кода.

```javascript
if (year == 2026) {
  alert('Вы правы!');
} else if (year < 2026) {
  alert('Рановато...');
} else {
  alert('Уже прошло.');
}
```

### Тернарный оператор `?`
Используется, когда нужно присвоить переменной одно из двух значений в зависимости от условия. Называется «тернарным», так как имеет три операнда.
* **Синтаксис:** `let result = условие ? значение1 : значение2;`

## 5. Логические операторы
В JavaScript есть четыре логических оператора: `||` (ИЛИ), `&&` (И), `!` (НЕ) и `??` (разбирается отдельно).

### `||` (ИЛИ)
* В логическом контексте возвращает `true`, если хотя бы один операнд равен `true`.
* **Запинается на «истине»:** Вычисляет операнды слева направо. Приводит каждый к логическому типу. Если результат `true`, останавливается и возвращает **исходное** значение этого операнда. Если все `false`, возвращает последний.

```javascript
alert(1 || 0); // 1
alert(null || 'текст' || false); // "текст"
```

### `&&` (И)
* В логическом контексте возвращает `true`, только если все операнды равны `true`.
* **Запинается на «лжи»:** Вычисляет операнды слева направо. Если результат `false`, останавливается и возвращает **исходное** значение этого операнда. Если все `true`, возвращает последний.

```javascript
alert(1 && 5); // 5
alert(1 && null && 2); // null
```

> **Приоритет:** Оператор `&&` имеет более высокий приоритет, чем `||`.

### `!` (НЕ)
* Приводит операнд к логическому типу и меняет его значение на противоположное.
* Двойное `!!` используется как быстрый аналог функции `Boolean()`.

## 6. Операторы нулевого слияния и присваивания: '??', '??='

### Оператор нулевого слияния `??`
Этот оператор предназначен для выбора первого «определённого» значения из списка. 
* **Разница с `||`:** Оператор `||` считает ложными значения `0`, `""`, `NaN`, `false`, `null` и `undefined`. Оператор `??` считает «пустыми» **только `null` и `undefined`**.

```javascript
let height = 0;
alert(height || 100); // 100 (0 посчитался как false)
alert(height ?? 100); // 0 (так как 0 — определенное значение)
```

### Оператор нулевого присваивания `??=`
Позволяет присвоить значение переменной только в том случае, если текущее значение переменной равно `null` или `undefined`.
* **Синтаксис:** `x ??= y` (эквивалентно `x = x ?? y`).

```javascript
let user;
user ??= 'Аноним'; 
alert(user); // "Аноним" (так как переменная user была undefined)
```

# Конспект по JavaScript 
## **1. Циклы while и for**

Циклы используются для многократного повторения одного и того же участка кода (тела цикла).

*   ### **Цикл `while`**
    Выполняет код, пока условие истинно.
    ```javascript
    let i = 0;
    while (i < 3) { // Выведет 0, затем 1, затем 2
      console.log(i);
      i++;
    }
    ```

*   ### **Цикл `do..while`**
    Сначала выполняет тело цикла, а затем проверяет условие. Код выполнится **минимум один раз**.
    ```javascript
    let i = 0;
    do {
      console.log(i);
      i++;
    } while (i < 0); // Условие ложно, но 0 успеет вывестись
    ```

*   ### **Цикл `for`**
    Самый распространенный цикл. Состоит из начала, условия, шага и тела.
    ```javascript
    // for (начало; условие; шаг) { тело }
    for (let i = 0; i < 3; i++) { 
      console.log(i); // Выведет 0, 1, 2
    }
    ```

*   ### **Прерывание цикла: `break` и `continue`**
    *   `break` — полностью **прерывает** выполнение цикла и передает управление на строку после него.
    *   `continue` — прерывает текущую итерацию и **переходит к следующему шагу** цикла.

## **2. Конструкция "switch"**

Конструкция `switch` заменяет собой несколько ветвлений `if`. Она сравнивает выражение со случаями `case` на **строгое равенство (`===`)**.

```javascript
let arg = '2';

switch (arg) {
  case 1:
    console.log('Это число 1');
    break;
  case '2': // Сработает здесь, так как типы данных и значения совпадают
    console.log('Это строка 2');
    break; // Если убрать break, выполнение пойдет дальше в case 3
  case 3:
    console.log('Это число 3');
    break;
  default:
    console.log('Значение не найдено');
}
```
 **Важно:** Если пропустить оператор `break`, код продолжит выполняться в следующих `case` без проверки условий.

## **3. Функции (Function Declaration)**

Функции — это основные строительные блоки программы. Они позволяют избегать дублирования кода.

### **Синтаксис Function Declaration**
Функция объявляется с помощью ключевого слова `function`:
```javascript
function showMessage(from, text = "текст не указан") { // "текст не указан" — значение по умолчанию
  console.log(`${from}: ${text}`);
}

showMessage('Аня', 'Привет!'); // Аня: Привет!
showMessage('Иван');          // Иван: текст не указан
```

### **Ключевые особенности:**
*   **Локальные переменные:** Переменные, объявленные внутри функции, видны только в ней.
*   **Внешние переменные:** Функция имеет доступ к внешним переменным и может их изменять.
*   **Возврат значения (`return`):** Функция возвращает значение. Если `return` пустой или отсутствует, функция возвращает `undefined`.
*   **Hosting (Поднятие):** Функцию, объявленную как *Function Declaration*, можно вызывать **до того**, как она описана в коде.

## **4. Function Expression (Функциональное выражение)**

В JavaScript функция является особым типом значения. Её можно присвоить переменной, как строку или число.

### **Синтаксис Function Expression**
```javascript
let sayHi = function() {
  console.log("Привет!");
}; // В конце обязательна точка с запятой

sayHi(); // Вызов функции
```

### **Главное отличие от Function Declaration:**
Функция, созданная как *Function Expression*, создается только тогда, когда поток выполнения доходит до неё. До этой строчки вызвать её **нельзя**.

## **5. Стрелочные функции, основы**

Стрелочные функции (`arrow functions`) — это краткий и удобный синтаксис для создания функций.

### **Синтаксис**
```javascript
// Полная запись
let sum = (a, b) => a + b;

// Если аргумент только один, скобки вокруг него можно опустить
let double = n => n * 2;

// Если аргументов нет, скобки должны быть пустыми
let sayHi = () => console.log("Привет!");
```

### **Многострочные стрелочные функции**
Если тело функции развернутое, его нужно брать в фигурные скобки и явно писать `return`:
```javascript
let ageCheck = (age) => {
  if (age >= 18) {
    return true;
  } else {
    return false;
  }
};
```

## **6. Особенности JavaScript**

JavaScript — это мощный, но своеобразный язык со своими ключевыми фишками:

*   **Динамическая типизация:** Одна и та же переменная может сначала хранить число, а затем строку (`let x = 5; x = "пять";`).
*   **Автоматическое вставление точки с запятой:** JavaScript часто сам понимает, где заканчивается инструкция, но для безопасности рекомендуется всегда ставить `;`.
*   **Строгий режим (`"use strict"`):** Современный режим работы. Позволяет избежать старых архитектурных ошибок языка. Должен находиться на самой первой строчке скрипта.
*   **Объекты и примитивы:** Всё, что не является примитивом (string, number, boolean, symbol, null, undefined, bigint), является объектом. Объекты копируются по ссылке, а примитивы — по значению.
*   **Окружение:** Изначально язык создавался для браузеров, но сейчас может выполняться на сервере (Node.js) и любых других устройствах через специальные движки (например, V8).
